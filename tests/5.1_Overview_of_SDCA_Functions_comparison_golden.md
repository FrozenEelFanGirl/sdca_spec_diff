## Overview of SDCA Functions

### Introduction

SDCA defines a number of Function Topologies, which are described in this Section (5). These are conceptual descriptions of how software views the internal signal paths within a Device in order to control it, and do not mandate the layout of actual hardware implementations.

> **v1.0:**
> *Unchanged.*
>
An SDCA Device may contain up to 8 instances of SDCA Functions (sometimes shortened to “Functions”), which can include multiple instances of the same Function Type (except for HID). The Functions are addressed by a 3bit Function Number (see [Section 12.1.1 — Hierarchical Addressing of SDCA Controls](../sections/12.1.1_Hierarchical_Addressing_of_SDCA_Controls.md)). The available Function Types are described in [Section 5.1.2 — Function Type](../sections/5.1.2_Function_Type.md).

> **v1.0:**
> *Unchanged (besides index)*
>
